# 后台图像任务与更新说明（2.51.0）

## 使用行为

虚拟试衣和正面人台图在确认服务、选图及计费提示后提交为独立任务。提交完成即可离开生成页、切换底部页面或锁屏。个人页、生成页和持续通知均可进入任务中心，按全部、进行中、待处理及已结束筛选；详情显示排队、准备图片、请求生成、保存结果等实际阶段，不虚构百分比。

试衣结果直接进入原试衣历史。人台图先保留为待确认预览，可放大查看；明确点击“添加到裙子图片”后才追加到原服饰图片末尾，保留原主图及其他字段。丢弃预览和删除任务均需明确操作。删除任务不会删除已经保存的业务结果。

应用重启后保留任务和待确认预览；未结束任务标为中断，不自动重新发送付费请求。重新发起会读取衣橱中当前的服饰和可用图片，并再次确认。取消只停止本机等待，无法保证远端停止处理或计费。2.50 旧生成页已经留下的合法人台预览继续提供明确保存或丢弃入口。

手动检查更新时，新版本和当前已是最新版两种情况都能阅读最新发布正文。正文为可选择、可滚动的普通文本，缺失时明确显示回退提示。保持原静默自动检查、可信链接校验和外部浏览器下载安装流程。

## 持久化与执行

- Room 27→28 仅追加 `image_tasks`，不修改现有业务表。任务保存 UUID、服务、请求快照、阶段及结果引用，不包含 API Key。DAO、薄 Repository、AppModule 与枚举转换同步接线。
- 协调层在应用作用域接受提交和本地确认操作；页面 ViewModel 不再持有生成网络工作。用户启动的 `dataSync` 前台服务按串行队列执行，立即展示通知，使用有期限的唤醒锁、每任务 12 分钟超时及 `START_NOT_STICKY`；不开机重发。
- 执行前按任务固定服务读取该服务的加密 Key，原子捕获一次。请求发出前先持久化 `requestSent`。试衣结果和完成状态、人台预览及待确认状态分别原子提交；取消或清理不会删除已提交结果。
- 确认人台图前完整验证本机 PNG，事务读取最新服饰行并幂等追加。原服饰已删除时拒绝保存，仍可丢弃预览。任务完成后释放源图引用，只有运行源图和待确认结果继续保护文件。

## 备份与并发边界

备份格式 8/schema 28 覆盖任务 JSON、ZIP、CSV、预览计数与恢复后逐字段核对，格式 1–7 缺少任务数组时兼容为空。完成结果路径仅为信息，已删除的业务图片不会成为 ZIP 必需附件；待确认预览必须是可验证的完整 PNG。

恢复先检查结构和暂存图片，再停止并等待旧执行退出，然后替换数据库。仅恢复屏障的等待保持不可取消，确保页面离开后调用方仍持有备份串行锁和 ZIP 暂存目录，直到恢复结束。恢复不会启动付费请求。

图片引用租约与 Room 快照在同一事务内取得，覆盖整个 ZIP 导出或 JSON 恢复；任务取消、完成及丢弃引起的文件删除延迟至租约释放，并重新检查当前数据库引用。锁顺序保持 Room→租约锁，释放时先退出租约锁再检查数据库。恢复只清理本次激活且已经无引用的新文件，保留导入前旧文件。

- 全量 JVM：249 项通过。涵盖请求验证、阶段/恢复规则、官方 API 解析、备份格式及更新正文解析。
- 后端及既有持久化设备回归：48 项通过，含 7 项真实 Room 备份、15 项执行边界，以及原试衣/人台/默认资料/数据完整性用例。
- 更新对话框：11 项设备用例通过，七套皮肤浅暗共 14 张 320dp/2 倍字体实际截图归档于 `docs/visuals/2026-10-16-image-tasks/update-notes/`。

新增任务中心、详情、两类生成页及导航的 47 项设备回归全部通过；七套皮肤浅暗共 42 张任务界面实际截图归档于 `docs/visuals/2026-10-16-image-tasks/tasks/`。截图使用受控本机位图核对真实布局及图片组件，不充当衣服生成质量样片。正式包升级与发布回执在完成后补录。受控传输证明应用内执行、持久化和取消边界；本轮没有新增付费 API 调用，也不将受控传输或空队列服务检查描述为真实锁屏 HTTP 联调。
