# 服饰图片封面

裙子详情的图片区域下方显示页数和封面操作。滑到已有产品图或已添加的人台图，点“设为封面”，保存后返回新封面；第一张显示“当前封面”。列表、心愿、位置缩略图和详情均沿用首张图片，其他图片保持原有相对顺序。

保存由 ViewModel 的 StateFlow 和应用现有 Room 数据流驱动，正在设置时阻止重复操作并显示状态，失败使用详情提示对话框。Repository 在事务内读取最新行并校验图片归属，只更新图片列表和修改时间；不提交旧 Item 快照，不丢弃并发追加的人台图，也不改动图片文件。重复引用保留，当前封面幂等，无图片、图片已移除或服饰已删除时不会制造新引用。

数据库版本 28、备份格式 8 不变。图片已有顺序直接参与原 JSON/ZIP 导出与恢复，不新增独立封面字段或一次性历史处理，也没有任何付费生成调用。

验证先在原版真实详情页面得到“当前封面”缺失的失败断言，再实现。`ItemCoverTest` 覆盖滑图选择、持久化、回到封面及全部图片保留；`MannequinPersistenceTest` 使用独立 Room 和真实 PNG，覆盖和追加的并发合并、最新名称/备注保全、重复引用、当前封面不更新修改时间、外部/空路径与删除记录拒绝，以及不同像素 PNG 的 ZIP 恢复顺序。沿用服饰导入恢复、编辑尺码与人台页面回归，设备仅使用独立 AVD。

正式包按仓库流程 clean 构建、原正式签名覆盖升级，GitHub/Gitee 同步发布。具体发布与数据保全证据在发布回执中单独记录。
