# 三列网格省略无品牌假发的品牌行

用户要求：假发没有品牌时，在三列场景不要显示品牌。

已查看工作区、项目规范及 ItemListViewModel → ItemCardData → ItemGridCard 的实际数据流。已跟踪源码干净，已有未跟踪资料全部保留。当前无品牌物品指向 `Brand.systemKey=unset_brand` 的系统占位，名称可为冲突避让后的变体，不能仅凭中文名称猜测。

实现前先绘制[排布设计](../visuals/2026-10-18-wig-grid-brand/design.png)与[七皮肤浅暗对照](../visuals/2026-10-18-wig-grid-brand/seven-skins.png)，SVG同目录保留。图中缩略插图为概念示意，正式图片继续使用原有0.8比例Crop、皮肤圆角和LolitaShimmerImage，不改原图、完整预览或放大。

范围：只对服饰页三列网格中 `CategorySemantic.family=WIG` 且没有真实品牌的物品，省略品牌图标与文字整行，不占空白。真实品牌、其他品类、单列/两列和画廊沿用现有显示。依据稳定品类语义与系统品牌身份，不按假发名称、分类中文名或“未设置品牌”文字匹配。

UI State传递系统占位品牌ID；网格在调用卡片时决定是否显示品牌。不删除或改写品牌与Item关系，不改Room30、备份10、图片、账本、任务、隐私出口或付费逻辑，无数据迁移或历史刷新。无品牌的编辑入口继续可用。

这是可逆的局部显示修复，不新增镜像实现的单元测试。按实际影响完成Debug构建、独立AVD真实网格检查与截图，核对三列无品牌/有品牌假发、其他品类及切回两列，维护长期约定。按项目要求更新为2.56.1/120、clean正式构建、同签名覆盖升级、提交推送与双端发布；验证与已知限制在完成后记录。
