# 参考图细节保真修复（2.61.1）

## 问题和范围

受控腰封原型说明，保留参考细节有实际价值；手工网格与蒙版仍只适用于一条腰封和一张底图，不能直接作为通用自动试衣发布。本次只合入自动、可验证的输入保真修复，不移植硬编码坐标，不改变生成提示词，也不承诺腰封贴合已解决。

现有 `TryOnImages` 对所有输入重新编码 JPEG90，即使原图已经足够小。高频柄图、蕾丝、链条及扣具会出现额外有损变化。本次在既有 EXIF 校正、最长边1536、透明区白底处理之后，优先编码 PNG；单张 PNG 超过4MiB才退回原 JPEG90。九张无损图最多36MiB，既有单张10MiB、总计40MiB及实际数量校验继续执行。高熵照片退回 JPEG 后仍执行原限制，不无声丢图或降低尺寸。

两个传输实现按归一化内容的 PNG 完整签名选择 MIME 和文件后缀，混合 PNG/JPEG 的顺序及字节均保持；不根据用户原文件后缀判断。不将未经校验的原文件直接上传，重新编码会去掉 EXIF 等私密元数据。
