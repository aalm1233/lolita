# Seedream 隐式水印适配

日期：2026-10-20。目标版本：2.60.2 / 130。

用户已在火山方舟开启隐式水印，应用仍写死 `watermark=true`，导致右下角继续出现可见标识。本次只调整共用传输层参数：试衣、单品展示、专属模特统一发送 `watermark=false`。隐式水印依赖用户已开启的服务端配置，不新增未公开的隐式水印参数，也不在本地擦除水印。

官方参数依据：[火山方舟图片生成 API](https://api.volcengine.com/api-docs/view?action=ImageGenerations&serviceCode=ark&version=2024-01-01)，`watermark=true` 表示在右下角添加“AI生成”标识。该开关与用户所述的服务端隐式水印配置分别处理；本地受控测试不能验证服务端隐式水印是否实际嵌入。

## 范围与兼容

- `ImageGenerationApi` 的三种 Seedream 操作均进入 `SeedreamImageApi.execute`，修改一处覆盖所有入口。OpenAI 请求不变。
- 只影响更新后尚未发出的请求；历史图片不处理，冻结提示词及输入快照不改写。不为此自动重发任务。
- API 返回的 Base64 解码后仍经原完整 PNG 校验并保存原字节，不重编码或清理生成结果元数据。原图、相册顺序、封面、生成来源与共享引用保持。
- 没有页面、组件或交互变更，故不新增界面图或七皮肤截图；既有缩略、完整 Fit、放大路径保持。
- Room30、备份10、本机设置和任务协议不变，无迁移。未改动业务字段、账本、统计、图片清理或备份，故不重复相关全库与往返回归。
- 上传内容、密钥存储、一次付费请求、无自动重试与原保存确认规则保持；本次仅执行受控接口测试，不调用真实付费生图。

## 验证与交付

更新三类入口既有传输测试的请求断言，定向运行 `SeedreamImageApiTest`、`MannequinApiTest`、`PersonalModelApiTest`，检查显式水印关闭、原图片顺序和数量限制、错误分类、取消及不自动重试。按项目要求完成 Debug 构建、已提交源码隔离 clean Release、原签名覆盖安装启动及双平台分发校验。最终实测结果另见本次发布回执；未实测服务端隐式水印检测或新生成图效果。

已通过 `assembleDebug` 及上述 11 项定向 JVM 用例（7 + 2 + 2），无失败或跳过；未调用付费 API。

本方案取代 `docs/seedream-provider-2026-10-16.md` 等历史记录中“请求开启官方可见水印”的当前实现描述，保留当时测试事实。
