# 实验室与统一展示图（2.65.0）

## 用户目标与范围

普通单品展示图统一走既有主视图→透明分层→人工核对→确认素材流程；已确认透明图片既作展示图也用于试衣。已有图片管理页只展示当前结果与使用/封面操作，重新生成回到同一批量流程，不重复展示逐件生成表单。单品保留一个普通生成入口。全头假发戴头模继续使用独立 MANNEQUIN/WIG_HEAD 流程，不改其模板、费用与历史。服装旧人台/普通小物旧生成入口退出详情，历史待确认与重试保持原协议。

个人页新增一级“实验室”卡片，收纳批量展示图、试衣、个人模特、假发头模、识图录入、任务中心和 API 配置。识图录入进入原物品编辑器，添加图片后主动框选识别；不自动调用。假发头模打开可搜索假发选择器，已有头模设置仍在原流程。已有业务上下文内的试衣/识图/配置快捷入口继续保留。

## 图片与数据

显式“设为封面”先复核当前素材 ID、类型/组合、私有透明图片完整性与 SHA256，再在同一事务将素材路径添加到最新相册首位并写 AI_GENERATED 来源。相册与素材共享同一图片字节；既有引用保护阻止移除/替换素材或删除任务时误删封面。重复设置不重复图片，原相册顺序相对保全；不覆写备注、价格、状态或位置。不自动设封面，不在保存时批量改封面。

无新表字段，Room32/36实体、备份13不变；既有 ZIP 路径去重映射及来源元数据支持共享引用，JSON/CSV沿用已有字段。补共享图片 ZIP 往返、删除/替换素材、陈旧 ID/类型/字节变化拒绝及并发设置回归。旧任务与旧备份语义不变。

## 隐私、费用与验收

入口迁移、查看与设置封面完全本地，不新增服务调用或密钥字段。原分阶段费用确认、实际输入快照、后台队列、失败不自动重试保持。新真实生图调用计划为0；受控矢量图片只证明流程。

验收：定向覆盖封面事务与来源/ZIP/引用保护、入口路由、普通单品唯一生成入口和假发独立头模；真实七皮肤浅暗、320dp两倍字体与真实 IME。执行 Debug、提交归档 clean 原签名 Release、上一版同签名覆盖启动、GitHub/Gitee附件与公开更新入口校验，不重跑应用内网络更新检查。
