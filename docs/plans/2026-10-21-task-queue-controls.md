# 任务队列停止与批量舍弃

用户反馈排队后不能停止后续、不能批量抛弃。以2.65.0源码为基准，本次覆盖后台图像任务中心和素材批次；不增加自动重试、恢复队列或批量删除已保存资料。

先以艺术设计角色绘制信息层级、留白和确认状态，再归档七套浅暗。前置图稿：[入口与确认](../visuals/2026-10-21-task-queue-controls/flow.png)、[浅色七皮肤](../visuals/2026-10-21-task-queue-controls/skins-light.png)、[暗色七皮肤](../visuals/2026-10-21-task-queue-controls/skins-dark.png)、[320dp大字](../visuals/2026-10-21-task-queue-controls/small.png)。HTML为可查看概念设计，真实Compose另行验收。

现有数据流为Room ImageTask → Repository → StateFlow → 任务中心/批次；所有已接受操作由应用作用域Coordinator持有。任务中心只有详情单条操作，批次原有逐条停止会让执行器在取消间隙领取后续项。

共用队列区展示真实排队、执行、待确认数量，不随列表筛选缩小操作范围；批次页仅作用于该批。停止按钮冻结本次排队ID，确认时在执行器同一状态锁与Room事务中一次取消仍排队的任务，已开始项跳过，当前任务继续。原“停止本批未完成”仍可取消当前执行，但先整体停止排队项再取消执行，避免串行逐项的领取竞争。后来新建任务不受陈旧弹窗影响。

批量舍弃弹窗冻结本次候选，默认零选择，支持全选/清空、逐项勾选、完整Fit缩略和点击放大。确认仅处理仍待确认的选中项，一次事务改为DISCARDED并清除未保存预览/分层引用，原图、已保存素材、相册、个人模特和任务记录保留。返回取消不写入；重复点击及同时保存、删除、状态变化均重新检查，不覆盖已确认结果；提示实际处理数。使用共用皮肤组件和令牌，操作自然高度/通栏，弹窗内容滚动、按钮固定，小屏大字不挤压；不新增输入框或键盘交互。

Room32、36实体、备份13与请求v1～6不变，无结构迁移或历史刷新。取消/舍弃沿用现有终态和备份语义；私有文件引用保护与备份租约继续保护共享图片。旧任务按原keepSourceImages策略保留冻结输入。定向覆盖旧单件/新批次、并发领取/迟到结果、原资料/共享图、ZIP往返、失败与重复操作。账本、位置、提醒、统计没有新写入。所有操作本地，不读取密钥、不上传图片、不调用收费API；已发送请求可能继续计费。

验收：受控执行器阻塞当前任务后停止其后所有排队项，断言只发一个请求；批次停止不影响别批、新提交不被陈旧确认扫入；舍弃混合主视/层/个人预览并保护已保存项，重复/陈旧确认可重复调用；真实Compose两入口、选择/放大/返回/提交、七皮肤浅暗和真实320dp两倍字。改后Debug构建、正式源码提交、归档clean原签名Release、覆盖安装启动与双端发布按AGENTS执行。新增真实生图调用计划0次。
