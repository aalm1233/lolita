# 两轮体验设计实施

依据已归档的[第一轮图稿与规格](2026-10-22-creative-experience-review.md)及[第二轮图稿与规格](2026-10-22-creative-experience-review-part2.md)，用户于2026-10-22要求开始实施。

实施顺序：

1. 修复个人金额隐私与精度；价格／付款采用唯一文字保存；备份突出ZIP并保留真实导出结果。
2. 完成衣橱／穿搭空态、实验室目的入口、紧凑试衣人物及先选物品、任务结果缩略与状态动作。
3. 收纳封面与管理折叠、订单文件旁的指南入口；检查背景可读性与底栏大字安全区。
4. 定向构建与业务／UI回归；七皮肤浅暗、320dp两倍字和真实IME对照原稿；提交、隔离clean正式构建、原签名覆盖升级及双平台发布。

数据边界：优先只调整展示、只读投影及导出结果页面状态；不变更Room／备份格式、原图、订单／实付、拥有状态、任务冻结协议。不调用付费AI服务。装饰图不得冒充实际库存或生成结果；使用现有图片与皮肤符号表达用途，业务缩略图完整Fit。

验收按最终差异选例。金额开关实时隐藏文字及语义；新建／读取失败不可错误保存；ZIP/JSON/CSV的原文件与返回URI一致；任务缺图／已删资料有回退且不误标保存；原选择、批次控制、历史与恢复警告保留。纯布局不重复无关全库审计。

实施与发布结果在完成后记录到 `docs/creative-design-implementation-2026-10-22.md`；前两轮文档保留历史提案身份，由本记录标明最终采用范围及差异。
