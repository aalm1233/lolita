# 价格第三批：独立参考价、退款与取消

2026-10-23。用户明确要求完成第三批并以模拟器验收、提交发布。基线2.69.0／144，目标2.70.0／145。本次工作区原有未跟踪资料保留。

## 前置界面设计

四页[交互稿](../visuals/2026-10-23-price-phase3-design/concepts.html)先于应用实现：独立参考价、退款与取消总览、到账表单、取消订单确认。各页七皮肤浅暗完整PNG及320px两倍字体位于同目录；浏览器检查只验证图稿布局。甜美采用柔软手账，其他皮肤沿用既定账簿轮廓及令牌，不新增图标或业务图片。实现使用LolitaSection／EditorSaveBar、真实七套provider、自然高度与真实IME。

- 参考价：从物品价格页进入，金额与来源备注在同页；保存只更新本物品参考值，不创建Price／OrderBinding／Payment、不改变状态。心愿统计使用独立参考价，旧订单不推断迁移。建单时仅通过主动采用填草稿，仍需确认保存。
- 售后总览：原实付、已退回、净支出、取消后待退款并列，金额隐藏时无数字或金额语义。原实付和退款分别列出；未到账的约定不计入资金流。
- 到账：退款／退差价两种明确类型，实际到账金额、实际日期、备注、保存预览，超过可退余额就地反馈。选择类型不改原订单总额或阶段。退款不重新生成欠款，也不自动减少尚未付的计划；终止购买使用取消流程。
- 取消：明确整个当前订单（含共价小物）回到心愿、原位置引用保留但不参与拥有库存，停止待付及提醒。必须主动确认约定退款总额（含已到账；不退定金可填0），或明确选择“金额待确认”，不预填为已到账，不删除订单、照片或付款。已取消订单仍可录到账、修订约定退款总额及查看原账本；再次购买新建订单，不能把已取消订单设为当前。
- 误记纠正：退款记录可明确撤销并保留原记录及撤销时间；它不表示实际向商家付款。普通付款撤销／编辑不得使累计有效退款超过原实付。

## 业务与数据

Room34追加三表：ItemReferencePrice（itemId唯一，amount、note、revision）；OrderRefund（priceId、正数amount、kind、receivedAt、note、operationId唯一、voidedAt）；OrderCancellation（priceId唯一、可空expectedRefundTotal、cancelledAt、note、revision）。原Price／Payment／Stage和购买证据不改。退款净支出=原实付−有效到账；取消待退=max(约定总退额−有效到账,0)，约定金额未知时待退继续未知；到账表单默认空白，不采用约定金额。金额用整数分计算，0参考价合法、退款须大于0，输入金额最多两位小数。

参考价保存采用revision CAS；退款／取消通过原OrderLedger串行事务与指纹重读，稳定operationId保证重试幂等。取消移除当前绑定并更新物品状态，既有RestoreJournal负责取消提醒；原订单及来源回执保留。已取消订单禁止付款、改计划、重新绑定；仅允许明确的到账／约定管理。旧资料无法确认实付时不猜退款上限，先补齐可确认的付款证据。

预算按实际到账月份扣减退款，清楚显示付款／退款／净支出；跨月退款可使本月净支出为负。全部已录付款继续保留原口径，新增全部退款／净支出，原消费图表继续明确表示原实付。付款年历原应付／实付日期保留，取消订单不再有待付；退款明细可由售后页和预算进入。

备份15完整支持JSON／ZIP、预览、CSV、引用及金额校验；旧1—14新增集合为空，不修改旧订单或把其猜为参考价。新增表采用外键引用原物品或订单。无新增图片字段、原图复制、网络支付或付费服务；本功能仅本机记账，不向商家实际发起退款或取消。
