# 广场本地资料包第一版

2026-11-05。用户授权先实现本地包导入，后续再由云端同步。延续[广场前置设计](2026-11-05-square-design.md)，本轮仅离线公开目录，不接网络服务，不访问淘宝。

前置艺术图稿：[导入关键状态与七皮肤浅暗](../visuals/2026-11-05-square-import/design.html)，渲染图同目录 design.png。图稿先于原生界面实现。

实施顺序：版本化包与离线转换 → 安全校验与原子目录更新 → 广场导航、筛选和详情 → 选择完整SKU并建立既有服饰编辑草稿 → 定向设备验证、正式签名构建与交付。

本轮采用可重导入的公开目录文件，不更改 Room34 / 备份15。衣橱登记复用现有 ItemDraft / Item.importToken / 编辑器：心愿、独立UUID图片和来源说明均进入原备份。公开目录不混入私人衣橱备份，可由同一ZIP恢复；云端将使用相同 schemaVersion、稳定店铺/动态/商品/SKU标识与单记录revision。导入只追加/更新明确出现的记录，不因某次包缺少旧资料而删除。

首次体验先支持整组登记及从明确组合选择其中一件，每次进入原服饰编辑器核对后保存；不实现设计中多件同时提交、批量建立衣橱套装的新事务流程。组合完整购买内容与逐件未知规格保留在来源说明，整组与单件有不同去重标识。组合价不复制到单件，不建立订单/付款/收纳。参考价保留来源文本，由用户在既有参考价页主动录入。本次取代原设计中拟议 Room35、备份16 的实施安排，迁移方案仍为未来独立原子多件登记的待选方案。

包格式为 ZIP 根 manifest.json + images/SHA256.ext。保留14条商品链接、542条完整SKU与三店当前原图，公开资料中明确套装、小物、颜色、风格、包含/不含/赠品及价格阶段。排除原始页面、账号资料和跳转截图；促销图作为独立角色，不作为商品主图或登记相册。

导入入口使用系统文件选择器，只读取用户选择的ZIP。校验包版本、唯一标识、全量引用、规范路径、SHA256、字节数、图片解码尺寸及解压上限；重复条目/穿越/未知格式均失败，暂存未通过不写当前目录。导入预览后才应用，失败旧目录可用。导入在ViewModel执行，旋转保留进度；取消预览清理暂存。启动清理中断的暂存文件，不删除正式目录。

列表封面适度裁切，详情主图完整Fit；主图/规格图/详情图/促销图分别浏览，原图可全屏缩放。登记复制所选商品完整主图与规格图、全部详情图，无50张截断；单商品图片不超过80MiB，每张20MiB，超限明确拒绝。

隐私与费用：完全本地，不上传、不请求付费服务。包中价格均为采集快照，尾款不可登记为新物品，价格区分全款/定金/尾款/下架占位。采集日期不冒充上新时间，无年份日期不补年份。

验收覆盖真实首包、重复/更新、坏包保全、离页/旋转、完整SKU同一组合筛选、三店全图、默认心愿与尾款只读、独立图片、七皮肤浅暗、小屏大字；构建与实际结果见后续实施记录。
