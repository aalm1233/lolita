# 广场浏览与直接心愿实施

依据已确认的[图稿与设计](2026-11-06-square-browse-first-design.md)，采用最终文案精简稿。实施前已检查工作区、现有目录、草稿、Item、来源及备份链路。独立工作树保留未发布采集工具和用户资料。

1. 建立浏览投影，按明确单品/款式组织颜色、尺码、图片、参数和来源报价，未知规格不绑定首条SKU。保留旧完整规格登记与草稿恢复。
2. 新增直接心愿用例：冻结目录版本、精确查重和相关记录、UUID图片暂存清单、有效品牌/类型、一笔事务保存多件或个人组合；不建账本或关系。来源使用SQUARE_WISH v1，Room34不变，备份16兼容1—15。
3. 按图稿改造广场两列图片、商品主图/单品/颜色/参数及轻量多件面板。默认心愿保存留在原处，查看进入现有物品/心愿页；补充说明用info tooltip。
4. 补无独立图片/未知类型边界图；实施后以真实Compose/模拟器核对七皮肤浅暗、小屏大字、图片放大、保存返回、重复/组合/旧草稿、备份往返及失败保护。最后按项目约定构建发布并核验。

应用目标2.74.0；实际完成范围、测试、原生对照和发布结果另记实施回执。当前计划不代表已完成。

边界图补充：[无独立单品图](../visuals/2026-11-06-square-browse-first/artist/missing-image.png)。缺图使用紧凑状态，继续可看已标明身份的系列图；参数未知与可加入心愿分别表达，不借整搭补单品图。

小屏原生实测修订：保存Snackbar会覆盖换行后的颜色项并误触“查看”，故默认单件保存只以主按钮“已在心愿 · 查看”及礼貌播报反馈，不叠加提示条；从选多件面板保存单件也显示实际输出回执。原型同步改为主按钮反馈，继续保留原位置。
