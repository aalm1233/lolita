# 广场、单品资料与物品详情第二轮

2026-11-06。用户实拍指出：筛选区过高，大图挤走商品名称；系列下的具体单品与小物组合共用整条链接的图片；详情信息和视觉不清晰。本轮按艺术家前置设计 → 七皮肤浅暗 → 原生改造 → 独立模拟器审视推进，不访问淘宝。

实施计划：
1. 对已采集三店原始SKU图片、详情OCR和部件事实建立可核对的单品图片归属，保留未归属的系列资料。更新本地资料包，旧v1包仍可导入和手动选图。
2. 依据艺术图稿重排广场列表、商品详情、部件选择和衣橱物品详情。搜索/筛选紧凑呈现；先看到图片与商品名，再看次级资料。图册完整Fit、可放大。
3. 对一个实际SKU中的明确部件允许整组、逐件或自主勾选组合；每个登记项分别核对照片、资料图与封面，未知次件颜色/尺码不继承主件，组合报价不分摊。创建持久编辑草稿后逐件核对保存，可暂停续办；不自动建立订单、套装或主件关联。
4. 原生验证三店实际资料、图片不串款、拆分/合组、重入与查重、旧包/旧备份、图片独立引用、金额隐私，以及七皮肤浅暗和小屏大字/键盘。最后完成正式同签名覆盖升级及发布。

艺术家图稿归档在 `docs/visuals/2026-11-06-square-refinement/artist/`。本轮不调用付费识图或生成商品图，不生成商标，不修改用户旧物品、订单、付款或旧照片。数据结构与备份影响按最终实现补记。
