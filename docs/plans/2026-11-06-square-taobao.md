# 广场商品外跳淘宝

用户希望在广场商品详情直接前往淘宝。现有公开目录的`SquareProduct.url`仅在来源文字中呈现；浏览单品会按当前颜色/尺码筛选来源行，同一单品可能关联全款、定金等多个链接。此次只增加主动外跳入口，保持现有逛选与直接心愿流程。

前置艺术图稿在实现之前产出：[商品](../visuals/2026-11-06-square-taobao/artist/product.png)、[七皮肤浅色](../visuals/2026-11-06-square-taobao/artist/light.png)、[七皮肤暗色](../visuals/2026-11-06-square-taobao/artist/dark.png)、[关键状态与320dp两倍字](../visuals/2026-11-06-square-taobao/artist/states.png)。本地照片与皮肤素材来自上一轮已核验图稿，完整Fit、无原图改写；HTTP/HTTPS渲染请求被拦截。以上为设计，不代替原生验收。

采用方案：商品摘要下、颜色上方放通栏描边“淘宝查看”及皮肤OpenInNew图标，底部加入心愿继续作为主操作。尾款页同位置提供入口，仍无心愿登记。使用当前单品/颜色/尺码对应的来源集合；一个有效链接直接外跳，多个打开可滚动选择框，逐条显示原商品标题和价格阶段，不显示金额。取消留在详情。不自动选择定金或其他链接，不携带私人尺码等追加参数。无有效淘宝来源时显示不可用入口“暂无淘宝链接”。

优先通过ACTION_VIEW的HTTPS原链接指定淘宝应用；未安装/无法处理时交给系统HTTPS处理程序。全部失败给中文提示及“复制链接”恢复动作。仅接受无用户信息、默认HTTPS端口的taobao.com/tmall.com及其子域；目录的其他HTTPS来源继续保留原文，不交给该按钮。无页面网络请求、网页采集、登录、下单、支付或私有数据上传，主助手不查看淘宝。

复用现有皮肤按钮形状、主题颜色、文字规格和OpenInNew键，不新增图标或主题令牌。按钮最小48dp，文字自然增高；大字不将两个主操作挤在同一行。选择框正文可滚动，关闭按钮可达；此操作不涉及输入及IME，现有搜索不改。图片缩略、完整预览、放大及原图引用均沿原实现。

无新实体/字段/持久设置，Room34/备份16及旧备份兼容不变；不写Item、来源、价格、账本、统计、提醒或图片。离开与返回沿原ViewModel/SavedState保留上下文，不创建新的内部路由。发布为2.75.0/152。

验收按实际影响覆盖：Debug构建；真实Compose普通/尾款入口、当前规格对应链接、多来源选择/取消、无效来源、淘宝优先/浏览器回退/均不可用及复制；七皮肤浅暗、320dp两倍字截图并对照。外部Intent使用受控Context捕获，禁止测试实际访问淘宝；不把受控接收冒充已安装淘宝真机验证。无数据库/备份/图片变更，不重复无关全库审计。正式包按仓库约定提交归档clean Release、原签名覆盖安装启动、双平台附件和更新检查核验，结果另附。

原生对照修订：真实目录标题比概念稿示例更长；选择行显式使用皮肤cardShape而非默认胶囊形，文字改用onSurface，防止两倍字下长内容被椭圆裁切。打开失败的Snackbar操作改为独立下一行，避免大字提示被操作按钮挤成逐字列。尾款入口在小屏需滚动，测试通过LazyColumn定位实际节点而非假定已组合。主图、字号、SKU与底部心愿逻辑不改。
