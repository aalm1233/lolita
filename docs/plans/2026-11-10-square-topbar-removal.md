# 广场按钮精简与搜索收起（2.78.9 / 165）

## 第一阶段：移除顶栏操作

用户要求将广场右上角按钮全部去掉。现有三个操作是查看心愿、导入资料包和广场服务。采用方案：标准 GradientTopAppBar 仅保留广场标题，商品详情保留左侧返回；不迁移或新增菜单入口。删除失去入口的服务地址、开发者工具和清空确认弹窗及其本页面临时状态。

这是删除现有操作，没有新增功能、布局组件或视觉素材；不绘制新艺术图稿，使用现有七套皮肤的标准空 actions 顶栏，真实 NavHost 七皮肤浅暗验收归档。页面搜索、筛选、下拉刷新、商品详情、收藏与结果中的查看心愿照旧；空目录原有导入按钮保留。

只修改 SquareScreen 呈现层。原内置地址、已保存的自定义/空地址和网络静默失败语义保持；不覆盖配置或清理缓存。Room34、45实体、备份16、衣橱与账本、原图/缩略图管线均不变，不新增权限、上传或付费。本轮无需数据库迁移或完整备份/图片SHA回归。

验证按影响选例：Debug、现有Haze NavHost七皮肤浅暗切换（删除旧齿轮弹窗步骤，核对三个操作均不可见）、完整浏览收藏导航、离线下拉刷新和空态导入。旧服务弹窗专属用例删除，其网络、配置恢复、缓存并发和私人资料保全用例保留。小屏/大字只复用现有顶栏矩阵检查；无新增输入框，不再测试已删除服务地址IME。正式版本2.78.8/164按提交源码隔离clean签名构建、2.78.7覆盖启动和双平台发布核验。
