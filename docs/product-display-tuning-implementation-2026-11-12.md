# 单品展示生成调优

本轮已将前次研究接入App实际单件/批量展示生成，正式发布2.78.11/167。源码/标签`293ba84d`已推送，原签名APK在GitHub与Gitee发布；详见[正式核验回执](product-display-tuning-release-2.78.11-verification.json)。

## 实际变化

新增 `StandaloneProductPrompts`，由新建批量非人台请求及单件独立商品请求共用。固定裙装/衬衫人台、单独选择假发头模、旧素材主视/分层提示保持。不同入口不再对同一种单品采用互不一致的移除规则。

新请求用稳定类型、已确认组合、名称及登记颜色定位图中的目标，均按JSON描述数据处理；不发送备注、订单、付款、位置或身体参数。发送前在原费用说明告知字段，并在既有分类/图片说明文本列出冻结的名称、类型、颜色和组合。名称、颜色或组合在确认后变化时拒绝提交；实际图片、模板、服务与SHA保护保持。

完整假发明确移除头/颈/肩/胸台并留空内部，发片仍不能补成整顶；玩偶自身脸和身体属于目标，不能按人台删除。手袖明确排除上衣及其袖口，保留可见两只；鞋履明确保留带间开口，袜装不补未见腰/裆。要求保留链条连接、长发尖和绳端并留边，保持有证据的原角度，单视图不拼成多视图。

继续每件一张、一次已确认请求；没有识图前置、第二阶段或自动付费重试。旧任务执行使用原 `promptSnapshot`，不以新构造重建。请求结构和已有 `promptVersion=1` 的不可变快照格式不升级，Room34/45实体、备份16保持；新完整提示、身份和颜色已在原快照内保存，无需新列。用户确认才追加相册，不自动替换封面。

## 真实效果与限制

前轮121次以后本轮新增36次：旧批量提示12次、首轮候选12次、最终生产Kotlin传输4次、同提示重复8次。均一张成功输出，无自动重试或结果未知；累计157/500次，余343次，金额未读取账单。全部输入、提示词、输出和逐件评语仅存本机私有评估目录，原ZIP与619张原图SHA保持。

| 样本情况 | 原结果 | 新结果及边界 |
| --- | --- | --- |
| 多配色色卡，记录黑色KC | 同时返回三种颜色 | 补入登记颜色后，最终及两次重复均只返回黑色；褶皱和造型仍有改绘 |
| 手袖记录，原图穿在上衣上 | 提取了整件上衣和袖子 | 最终及两次重复均只保留两只手袖；蕾丝、朝向及形状仍有变化 |
| 白色鞋履，照片带腿袜 | 腿和袜子仍保留 | 首轮候选移除腿袜，只留一双鞋；鞋面蕾丝和鞋底不算严格保真 |
| 开口绑带靴 | 开口被填成封闭靴筒 | 最终三次有两次保留明显空隙，一次仍封闭；还出现方向镜像，不声明稳定修复 |
| 完整假发 | 旧单件提示保留头模；旧批量已可去头模，但可捏造背后长发 | 统一完整假发规则；三款候选去头模，最终白色卷发三次均无头模，未再出现原批量的大块虚构背发；卷度/发丝仍不完全相同 |
| 正背商品板中的腰封 | 将两张视角同时输出 | 候选只输出主视，但细绳、边缘和纹理仍重绘 |
| 多链腰封、Bonnet、长腰饰、另一对手袖 | 链条和系带变化，偶有裁切 | 未确认严格细节保真改善，保留失败和局限，不概括为全品类成功 |

这些是选定样本的主助手逐图核对，没有人类盲评或完整三视图真值，不外推总体准确率。App仍提供待核对的展示图，没有新增自动三视图入口，也不把生成图当真实规格。

## 验证范围

34项定向JVM覆盖新类型分流、完整假发与发片/头模区别、玩偶身体、空隙/成对约束、用户数据转义和旧任务快照往返；原裙装提示SHA保持。独立工具15项安全测试通过。Debug与AndroidTest构建通过。

实际设备验证采用独立Android15模拟器，模型与密钥边界受控，检查新提示实际入队并到达执行器、历史排队提示不重建、名称/颜色变更不发送、混合类型输入与保存、ZIP往返及不重发；界面覆盖七皮肤浅暗、真实320dp两倍字/IME和费用按钮。设备受控输出不冒充模型质量，4次最终Kotlin真实调用不冒充Android端到端网络调用。

最终29个去重设备方法通过，含图像校验期间并发改颜色在入队事务内回滚、两个ViewModel的陈旧确认/恢复/重试草稿、混合队列与ZIP。原位费用说明已精简；正常与320dp两倍字的滚动阅读、确认和返回可达。[七皮肤费用页](visuals/2026-11-12-product-display-tuning/native-fee-seven-skins.jpg)、[普通费用页](visuals/2026-11-12-product-display-tuning/native-fee-normal.png)、[小屏大字滚动核对](visuals/2026-11-12-product-display-tuning/native-fee-small-font2.png)、[单件目标确认](visuals/2026-11-12-product-display-tuning/native-single-confirmation.png)均为真实Compose加合成夹具，图中简单色块/插画不是生成质量样本。

首轮所谓普通界面检查误用了AVD保留的320dp两倍字配置，费用说明可见性断言失败；按实际普通配置复测通过。小屏说明经精简文案并按子内容滚动后核验可达，不能只把改变测试配置计为产品修复。单件系统窗口截图等待平台淡入结束，保留早期混叠截图但不作视觉通过。最终方法与截图以发布核验回执列明。
