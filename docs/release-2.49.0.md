# Lolita 2.49.0

裙子详情新增“生成人台图（实验）”。选择一张已有图片，可补充需要排除的独立小物，生成统一正面人台预览；放大核对后点击“添加到裙子图片”，结果追加到末尾，原图及主图顺序保留。

与虚拟试衣共用本机加密保存的 OpenAI API Key。API 单独计费，不包含在 ChatGPT 订阅中；应用不会自动付费重试。只生成正面，AI 可能改绘印花、蕾丝与比例，请核对后保存。

同时完善生成防重复、预览恢复、取消返回、保存后导航及旧记录删除时的图片清理。数据库和备份格式保持兼容。

本轮已做更多内置工具样片与受控应用回归；未使用真实个人 API Key 进行付费生成联调。
