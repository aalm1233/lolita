# Lolita 2.53.0

- 新增“我的模特”：根据照片和身体参数创建专属全身模特；仅填参数时使用虚拟面容。支持三处照片参考、可选围度、完整预览及本机草稿。
- 生成结果先留在任务中心，确认满意后保存，可设为试衣模特；支持改名、删除和以此调整。调整另存新模特，保留原模特和历史试衣。
- 虚拟试衣可切换内置或已保存的模特，切换不清除服饰选择。提交后固定本次底图，之后改默认或删除人物不改变排队任务。
- 个人模特、原照、草稿与待确认任务纳入备份；兼容旧备份和原有人台、试衣任务。Android 8.0/8.1 的个人参考照需使用完整 JPEG 或 PNG。

生成前会提示上传内容与实际图像服务，API 单独计费；中断后保留资料，需要主动确认重试，不会自动再次付费生成。相似度和体型还原受生成服务影响，不提供精确尺码或合身度预测。

沿用原正式签名覆盖升级，并保留服饰图片封面功能。
