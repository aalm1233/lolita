# 广场浏览与直接心愿 · 2.74.0

按用户确认的[艺术图稿](plans/2026-11-06-square-browse-first-design.md)实施。广场以真实照片卡片呈现；商品详情从当前单品、颜色、图片与对应参数开始，喜欢即可加入现有心愿。尺码可以暂不选，无需先拆分、选图和经过完整编辑器。

## 最终行为

单件保存留在原处，主按钮变为“已在心愿 · 查看”，返回保留选择与滚动。按需选多件可分别登记或合为一个个人组合；每件独立照片、颜色、尺码、资料，KC不继承裙码。默认保存心愿，不生成订单、实付、参考价或套装关系。尾款只读。

同批定金/全款仅经采集variantId明确连接，套餐中的部件与独立售卖对象避免重复展示；原始完整SKU及报价阶段保存为来源证据。未知色码不绑定第一条SKU，组价不下放。没有独立图采用紧凑缺图状态，系列图单列，不冒充单品封面。

信息补充用可点按、返回关闭的info tooltip；参数和尺码表直接阅读，完整资料与原图按需放大。关闭显示金额同步隐藏报价。常显文案未添加教学段落或slogan。

`SquareBrowse`投影公开目录，`SquareRepository → SquareViewModel → SquareScreen`接入现有数据流。`AddSquareWishUseCase`冻结目录修订、与备份共享操作锁，复制前持久记录UUID目标，事务中复核已保存来源/旧token/草稿，一次写入所有Item与来源。图片失败、陈旧请求、中途失败不留半组；提交后未收到UI结果按来源恢复。清理经过全局引用保护，删除一件不影响其他物品共用的来源图。

Room34、45实体不变。既有`ItemSourceRecord`增加`SQUARE_WISH` v1资料协议；图片为imagePaths索引，可随ZIP路径重映射。备份16完整导出、校验、恢复，旧1—15继续兼容；CSV增加可读成员/规格/阶段，不输出内部身份。旧广场登记草稿继续原编辑器，不静默覆盖已存物品。

公开包继续`lolita.square` v1，可附有严格行列限制的sizeTable。浏览版保留3店、10条、14商品、542SKU、421原图，补41个明确对应的部件表；莉莉子长短OP尺码列分别保留，不把套装含糊表编造成独立部件规格。[资料包校验](square-browse-package-2026-11-06-verification.json)。
