# 广场浏览与直接心愿 · 2.74.0

按用户确认的[艺术图稿](plans/2026-11-06-square-browse-first-design.md)实施。广场以真实照片卡片呈现；商品详情从当前单品、颜色、图片与对应参数开始，喜欢即可加入现有心愿。尺码可以暂不选，无需先拆分、选图和经过完整编辑器。

## 最终行为

单件保存留在原处，主按钮变为“已在心愿 · 查看”，返回保留选择与滚动。按需选多件可分别登记或合为一个个人组合；每件独立照片、颜色、尺码、资料，KC不继承裙码。默认保存心愿，不生成订单、实付、参考价或套装关系。尾款只读。

同批定金/全款仅经采集variantId明确连接，套餐中的部件与独立售卖对象避免重复展示；原始完整SKU及报价阶段保存为来源证据。未知色码不绑定第一条SKU，组价不下放。没有独立图采用紧凑缺图状态，系列图单列，不冒充单品封面。

信息补充用可点按、返回关闭的info tooltip；参数和尺码表直接阅读，完整资料与原图按需放大。关闭显示金额同步隐藏报价。常显文案未添加教学段落或slogan。
