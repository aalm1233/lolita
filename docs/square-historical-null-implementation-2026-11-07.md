# 广场历史空值兼容修复

按[修复计划](plans/2026-11-07-square-historical-null.md)完成。初步检查发现地址配置读取已有缺失/损坏回退，私人衣橱订阅虽存在未兜底风险，但没有证据证明与本次反馈同因，本轮未扩大修改它或历史衣橱。最终找到公开事件模型与旧解析器的实际缺口：`state=null`通过v1校验，Gson可将缺字段恢复为null；可见性投影直接trim导致主线程NullPointerException。

先行JVM用例在2.78.0源码失败；随后在独立AVD的线上原签名2.78.0中，仅替换公开目录描述字段为null并同步缓存摘要，私人Room及设置不变，实际进入广场发生同样`SquareVisibility.products → StringsKt.trim`崩溃。此为可重复的异常历史形状夹具，并非取得反馈者真实资料，不能宣称已证明现场同因。原反馈用户当前版本已确认为2.78.0，机型/系统/原始异常栈未知。

2.78.1／157将事件的描述性文字明确为可空；缺字段与显式null保留未知，非文字描述值拒绝。动态身份、引用、商品/SKU、原图校验及售卖状态规则保留。未知状态不推断下架，明确下架商品仍隐藏；日期/采集日期使用已有未知文案或包采集日期，未知价格显示“价格未知”，不补0或改变SKU报价。浏览搜索不把null作为关键字；尾款仍只读。原图、衣橱、账本、Room34／45实体／备份16、地址默认值与静默联网策略不变。
