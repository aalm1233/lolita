# 广场服务闪退：旧版直升排查

用户反馈点击广场右上角齿轮闪退，补充可能由“有广场之前的版本直接升级”触发；当前App版本已确认2.78.0。本文保留第一轮直升未复现的记录。后续从数据结构复现旧v1描述性null导致的独立崩溃，修复与现场同因尚未确认，见[后续实现记录](square-historical-null-implementation-2026-11-07.md)。

先前已核对线上同一2.78.0 APK在独立Android15环境的七套皮肤、320dp／两倍字与真实键盘打开。此次补充新建独立AVD，安装无广场的2.71.1正式原包，经正常备份选择器恢复当前固定测试资料；原包与设备工作副本SHA一致。旧备份页进入后台，保留旧任务状态，不在覆盖前force-stop；直接`install -r`同签名2.78.0，不卸载或清理应用数据。

覆盖前明确无广场服务配置、无公开目录缓存。首次进入广场并点齿轮，弹窗与地址字段正常；输入框能唤起键盘，取消返回正常。首次公网同步完成7店／31商品／15动态、游标15。此后主动冷启动，重新开弹窗并点“使用内置地址”后取消，仍正常，崩溃日志为空。

两处检查点均与旧版基线对照：45张表全部行字段指纹一致；629张本机图片文件SHA清单一致；既有偏好及持久配置字节一致。629包含恢复前已初始化并保留的本机图片；当前备份自身619图片不据此改称629。WorkManager SQLite的瞬态WAL/SHM不作为用户设置字节判据。私人资料、图片、设置及逐表指纹仅留本机，公开[汇总回执](square-service-crash-direct-upgrade-2026-11-07.json)。无付费调用。

局限：反馈者具体机型、Android、升级前确切版本及异常栈尚未取得。2.71.1与2.78.0均为Room34，此次不证明更早数据库迁移或其他Android／OEM环境无问题，也不能将“未复现”当作已修复。后续按历史数据形状继续排查，不将设备信息作为继续工作的前提。

本次只有验证记录，没有新功能、布局、数据结构、图片引用或持久设置规则变更；设计规范中的新图稿／七皮肤设计不新增，沿用现有已实现界面。纯文档无需升版本、构建或创建Release。测试AVD结束关闭并保留数据，原用户设备未操作。
