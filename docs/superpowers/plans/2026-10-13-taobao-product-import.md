# 淘宝商品链接导入试用版

复用已实测的 WebView 加载及 evaluateJavascript 提取路径。用户粘贴分享内容、在网页正常登录、点击提取、核对资料并进入现有服饰编辑。默认心愿状态，仅精确匹配已有品牌，不自动创建品牌或付款。价格及定金尾款正文留在来源说明，不推断用户购买规格。

1. 链接及网页数据解析：限定 HTTPS 淘宝商品/短链域名，校验商品 ID；解析结构化标题、品牌、规格、主图和价格，测试分享文本、非法域名、定金商品和缺失数据。
2. 新增皮肤感知商品导入页与 StateFlow ViewModel。WebView 仅加载淘宝及登录域名，不提供 JS bridge；主动提取，不采集 Cookie。下载用 ImageFileHelper，失败/取消清理，转入编辑页后由编辑 ViewModel 管理图片。
3. 商品草稿通过 SavedStateHandle JSON 交给编辑页；复用品牌分类选择、保存和放弃机制。入口位于已有淘宝订单导入页，新增 Screen 路由，版本 2.44.0/94。
4. 单元测试、assembleDebug、独立 AVD 同签名安装与网页/确认/编辑验证；clean assembleRelease 出试用 APK。只提交本任务文件，集成 master 并普通推送。

验证重点：恶意域名、网页不完整/登录中、切换商品后旧回调、图片失败及取消、价格为定金且无付款证据。试用版不增加数据库字段，现有图片/描述继续纳入备份。
