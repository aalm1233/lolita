# 非导航图标个性化设计

用户要求五个导航图标之外也全部个性化。已认可的 Home/Wishlist/Outfit/Stats/Settings 绘制文件保持字节不变。其余 46 个功能在七套皮肤中需要从主体轮廓、比例、构件和笔势体现差异，不能只改圆角或端点，也不能在相同符号外套同款装饰框。

沿用 Kotlin Compose Canvas、24×24 坐标、约 1.7 主线宽、调用方 tint 和尺寸，不新增资源或依赖。主题取向由本轮设计判断：甜系柔软膨润/布艺，哥特尖拱/切角，中华卷轴/毛笔/印章结构，古典文具与裁缝的对称结构，海军舷窗/航海器具，田园木作/手工/叶片，维多利亚羽毛笔/拱顶/珠宝。即便删除、分享、保存、加号、九宫格、下拉、显隐等基础控件，也要在 18dp 看出笔势或构件差异，同时能认出原功能。

图标不得加入通用盾牌、背板来缩小符号，不添加小而密的装饰。视觉差异应在同色同尺寸矩阵中成立。实心/空心星标共用轮廓；图片与添加图片下半部保持完全一致；断链/隐藏用真实间隙或剪裁，不能背景色盖线。透明度乘 tint.alpha。导航和页面布局、月份设计、数据库、版本不改。

以真实 Android 七套 provider 渲染检查全部图标，保留尺寸/矩形槽/tint/透明及半透明回归。审阅操作、内容、箭头、状态的浅暗矩阵和18dp细节；通过构建后同步本轮明确文件到主工作区，保全其他改动。当前请求不追加发布。
