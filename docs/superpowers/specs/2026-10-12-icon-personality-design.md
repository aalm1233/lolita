# 七套皮肤图标个性恢复

用户反馈七套图标都缺乏特色。本轮沿用已讨论的七套轮廓方向，恢复整套视觉身份。以下绘制细节与实施范围由设计负责人选择，可按真实尺寸效果调整。

## 目标与范围

- 七套 provider 覆盖现有 51 个 IconKey；导航、内容、高频操作都体现各套造型，不能只有底栏不同。
- 同色、24/26dp 下可见的主体轮廓、比例、虚实关系承载差异。圆角、几根细内纹、统一图形外加装饰框不能作为主要差异。
- 基础加号、箭头、关闭与状态保持明确功能语义，使用各套笔触与端部语言，不为差异而把符号换成无关物件。
- 保留 Canvas 矢量、24×24 逻辑网格、约 2 单位安全边距、主线宽 1.7、矩形居中等比缩放、tint 及透明度规则。无固定奶油色、Material 图标回退或图片资产。
- 尺寸、API、IconKey、七套 provider、业务页面与版本不变。先交付真实 Android 对照图和可运行 Debug，不在此次自动发布。

## 七套造型语言

| 皮肤 | 主体语言 | 核心对象与区分 |
|---|---|---|
| 甜美 | 饱满、柔软、圆润、紧凑 | 玩偶屋、泡袖蓬裙、圆瓣齿轮；软弧端部与饱满工具形 |
| 哥特 | 尖拱、切角、挺拔、清晰负形 | 尖拱建筑与棱形裙摆；切角工具与尖端连接，不叠小蝙蝠/十字 |
| 中华 | 飞檐、交领、收笔、几何转折 | 飞檐建筑与交领服饰；印章式边缘用于物件轮廓，不给所有符号套印章 |
| 古典 | 对称、直立、收束、克制 | 对称宅邸、规整 A 字裙、直框工具与清楚的端部；明显区别维多利亚 |
| 海军 | 灯塔、水手领、舷窗、简洁硬朗 | 海洋物件轮廓、清楚的 V 领与横向结构；保留灯塔主体，避免密集细绳 |
| 田园 | 宽檐、自然曲线、围裙、朴素 | 小屋、围裙、木框与枝条般曲线；主体不同于甜美泡袖裙 |
| 维多利亚 | 拱形、高腰、层叠、细长优雅 | 拱形宅邸、层裙与胸针式齿轮；用物件本身的结构表达华丽，不缩小功能符号套盾牌 |

## 文件与实现边界

- `PolishedNavigationIcons.kt`：五个导航图标，七套均有明显主体差异。
- `PolishedContentIcons.kt`：十四个内容图标；星标实/空心共用各自皮肤同一轮廓；图片/相机/日历/分类/位置/钱币等使用主题物件结构，链接/断链语义清楚。
- `PolishedControlIcons.kt`：十六个操作、九个箭头、七个状态；编辑、搜索、删除、复制、刷新和视图等高频操作强化主体，基础符号通过端部与笔触连贯。
- `PolishedSkinIcons.kt`：仅根代理维护公用网格与笔触契约。三个绘制文件独立使用现有 `SkinIconStyle`；不得互相依赖新私有 helper。

## 验收

复用真实 `SkinIconVisualTest` 渲染全部 51×7。验证亮/暗单色、18/24/26/32dp、矩形与透明 tint；导出完整矩阵、中文概览、26dp 概览。逐列检查系列连贯、同一 key 横向检查主体区别，特别检查古典/维多利亚、甜美/田园。

美观由实际图像审查，不编写硬编码路径或只验证圆角常量的测试。构建与现有单测通过后，独立审查代码和真实渲染；集成到主工作区时保留无关文件与原始行尾。
