# 第一轮页面视觉优化

用户已认可优先整理穿搭编辑、价格付款和淘宝导入指南；月份的紧凑布局为有意设计，保持原样。

- 穿搭编辑：日期、备注和关联服饰通栏，照片仍以网格展示。卡片只保留一层内边距，底部用明确保存操作；原照片、日期、选择与放弃更改流程保留。
- 价格付款：首屏突出当前账目的状态与金额，只有一个主要实付操作；次级核对和归档操作保留。详细解释可展开，阶段和实付各组成紧凑记录组。日期未知、余额未知、历史只读和确认警示始终明确。
- 导入指南：移除六块灰色截图占位，按获取文件、回到应用导入整理现有步骤和注意事项。无真实截图时采用紧凑文字，不虚构截图。
- 延续七套皮肤的颜色、字体、间距、圆角和现有图标，使用 LolitaCard / LolitaSection / SectionHeader。
- 只调整上述界面，数据库、账目计算、导入解析、月份、图标、首页顶栏和统计总览不在本轮修改范围。
- 图片及金额不可因视觉整理而丢失、推断、取整；长中文名称和大字体应能换行，键盘开启时文字和保存操作可达。
