# 商品提取与三视图评估

本轮完成121次真实火山请求，均返回一张图，逐张核对完成；500次上限剩余379次，无自动重试或结果未知。覆盖41件物品、30个实际商品类型。结论是：可改善单品概览提取，但尚不能可靠生成保真的完整三视图。现有样本仍出现结构重绘、角度混淆和无证据侧背补造，不将其接入正式App。

已交付独立评估工具、可复查的私有对照图册、证据约束拼板原型和全量完整性回执。原备份及619张原图SHA保持；个人图片和逐件资料不进入仓库。汇总见[核验回执](three-view-evaluation-2026-11-12-verification.json)。

## 范围与方法

用户于2026-11-12授权最多500次火山生成，可使用真实导出资料的全部图片。使用固定的2026-10-28备份入口，先验证原ZIP SHA、CRC和619张图片清单，再在仓库外建立工作副本。160件物品全部有可解码的商品图片；共30个实际使用的类型。36个图片条目有明确AI生成来源，不能作为新增侧背面照片证据。39个条目与其他条目内容重复，不合并或删除。

普通解码最初失败的4张历史文件均为HEIC而非后缀所示JPG，macOS ImageIO转换工作副本后619张全部可解码。该主机兼容处理不代表Android新增解码修复；原图字节保持。没有AI来源标记的图片也不能仅凭这一点证明照片真实性，最终仍逐图看来源内容。

测试分为直接三视图、证据约束三视图、多参考、独立提取后再生成、按真实已确认视角拆开提取及两种明确标注推测的研究板。原型使用Seedream 5.0 Pro，横板1536×1024、单视图1024×1536；逐次冻结提示词、输入SHA、输出SHA、耗时和服务返回数量。实际生产提示词与传输另行验证，不将主机原型当作Android调用链已通过。

本轮视觉核对由主助手逐张看图完成，尚未有人类盲评或真实多视角测量真值。核对分别检查目标/配色/件数、可见轮廓与细节、无关内容去除、裁切、方向及未知处理。接口HTTP200、完整PNG和商品保真是不同结论。没有已核验完整正侧背真值的物品，不报告“完整三视图准确率”；不能因为画出三件商品就认定有三个正确视角。

完整盘点不等于每张都付费测试：全量619张只读检查，实际生成选用41件物品的图片。两次早期对照使用已有AI展示图，另10次二阶段以生成结果为输入，均单独标明派生来源。部分原始资料确有正背或斜向照片，不能笼统说所有样本都只有正面；但这些照片尚不足以建立统一的完整正侧背测量真值。抽样及逐图评语不支持外推总体成功率。

## 已确认的问题

- 直接要求补齐三视图会把缺少证据的侧背画得很确定。单正面裙子可能出现三张相近正面；缺少背面照片的胸衣、包、旗袍会出现新背部结构。
- “未知”提示词不能作为强保证：裙装、袜装、包和旗袍样本出现一边写未知、一边仍画出未见背面的情况。
- 开口绑带鞋在单图和多张同色照片中均可能变成封闭靴筒。四张照片不等于四个有用视角，也不能保证模型保留带间空隙。
- 成对手袖可能变成单只；三种配色可能分别占据正侧背格，或被放在同一个前视格；名称指向手袖时也可能仍返回整件上衣。
- 胸针、腰封的系带、链条、扣具与连接关系会重绘。低分辨率、遮挡、裁掉腰部或下摆的图，不能靠生成结果恢复真实结构。
- 某些品类没有自然统一的“正/右侧/背”定义，如展开的阳伞。应先确认所需视图语义，不能硬套服装正侧背。
- 历史AI展示图可以作为派生输入对照，但不能与真实照片混合后宣称新增了背面证据。

多参考样本中的衬衫能较好展示正面，但两张正面照仍不提供背面。另有裙装多参考结果在第一格溢出、裙边贴画布；袜装原图未展示腰/裆，无法验证完整连裤结构。逐图评估保留这些限制，没有将“图更好看”代替结构证据。

## 已实现的调试工具

`scripts/image_eval/` 提供独立付费账本、全图盘点、逐件比较、生产传输探针、逐图证据视角拆分及本机HTML核验报告。代码不连接App Room或改私人相册。

证据约束原型先由主助手逐图确认某张实际参考对应的视角和目标区域。有证据的视角才创建提取请求；缺少视角由本地代码固定为空并标未知，模型不能在该格偷偷补图。相册中有明确AI标记的图不能用来补充照片证据；发送后不能重写原输入。生成结果默认不替换原裁切，只有逐图检查并明确提供结果SHA后才采用。每格Fit展示不提供等物理比例或厘米保证。

这条路线控制的是证据边界，不保证单次AI提取的所有蕾丝、柄图、细绳和空隙都保真。按已知视角分别提取也会增加调用数，原图裁切是零生成成本的对照和失败回退。

三款全头假发对照中，当前独立商品提示均保留头/颈/胸台；将含糊的“hair component”段落改成明确的完整假发与移除头模规则后，三张候选均去掉头模。改善仅限这三个样本：其中一张仍出现内部发丝合成与长发尖裁切，另两张卷度和发丝布局仍被重绘，因此没有修改生产提示词。候选段落原文如下，研究时应只用于已确认的 `FULL_WIG`，不能下放到发片：

```text
The selected product is already one COMPLETE FULL-HEAD WIG, not an extension. Preserve the complete existing wig, all hair fibers, tips, bangs, curls, braids and actual clips. Completely remove the source display mannequin, head form, face, forehead, neck, shoulders, stand and unrelated hair. Leave the opening beneath the hair empty with the same pale-gray background; never fill it with a scalp-shaped dome or invented hair. Do not create a new mannequin, body, cap, ribbon or missing companion. Retain the reference viewing angle and actual visible hair arrangement.
```

后续生产改造应先保留单品概览用途与原图回退，再单独验证细节、裁切和稳定性。未知方向的本地留空及推测来源标记可以确定性执行；保真提取仍需逐图确认，单靠加长提示词、再生成一次或提升分辨率无法作为保证。

## 保护与验证边界

500次是本轮上限，不与任何旧额度合并，也不以用满为目标。每次请求前加锁原子预留；失败、超时、结果未知都占一次，同ID拒绝重发。每次最多一张输出，无额外识图、分层、重定向或自动付费重试；小批次最多三路，遇额度/鉴权/限流停止派发。真实账单金额没有读取，不由请求次数推算费用。

原包、全部原图、个人资料、源图/派生图、实际提示词和逐件评语仅保留于本机私有目录；公开仓库只提交通用工具、汇总及方法。密钥通过本机600权限配置读取，不打印或进入报告。逐图标注错误同样保留记录：一个昏暗、文字覆盖的配饰套装曾被描述成无商品图，该提取作业从公平对比中排除，不回写实际已发提示词。

此次没有改变Android页面、生成任务协议、图片保存、版本、Room34/45实体或备份16，没有恢复原库或发APK。没有新增页面，艺术图稿和七皮肤验收不适用。研究板、模拟器/编译和真实生成分别报告，不将原型宣称为已上线三视图能力。

最终离线15项安全与证据边界测试通过，Python编译检查通过；`assembleDebug`通过，当前生产传输探针编译及4次实际调用通过。121次输入/提示词/输出、7张本地证据板及8张推测标记副本SHA复核无变化。预算并发测试以510次预留竞争验证恰好允许500次，无真实网络消耗。这些检查验证执行安全和文件保全，不能替代视觉质量结论或Android端到端设备验收。
