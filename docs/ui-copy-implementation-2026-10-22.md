## 数据与费用边界

Room32／36 实体、备份13、图片字段与引用清理均不变。仅新安装默认来源使用「闲鱼」；历史迁移中的旧值和用户已有来源不改名。用户描述、旧规格和草稿不因折叠被清除。个人照片、API Key 与受控测试配置未进入公开图片、主包或文档。

本轮不更改请求协议、冻结提示词、任务执行、付款计算、导入配对、价格采纳或保存条件。真实付费调用为零；原生测试图片是受控夹具，不证明 AI 品质。
