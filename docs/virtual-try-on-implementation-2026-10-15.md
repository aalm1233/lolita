# 虚拟试衣实验实现与验证

版本：2.48.0 / 106。基于已发布2.47.1审计修复合入，Room26→27，备份格式6→7。

## 应用能力

个人页、已拥有服饰详情和套装详情可进入虚拟试衣。用户在界面填写个人OpenAI API Key，选择1–8件服饰/小物、每件一张已有照片及穿戴位置，以固定成年虚拟模特生成单张搭配图。选择随搜索/分类保留，SavedStateHandle保存紧凑快照。角色先尊重具体分类，“其他配饰”再从名称建议。

官方接口为`https://api.openai.com/v1/images/edits`，型号`gpt-image-2.5-sunburst`、medium、1024×1536、PNG、n=1；上传固定模特加所选服饰照片、服饰名称和穿戴位置。页面固定操作区展示上传数量、服务方和可能计费。图片先校验最新Item仍已拥有、路径仍属于该Item、文件可读，再完整准备，禁止部分上传。透明PNG转JPEG时合成白色背景。

Key使用Android Keystore AES-GCM加密，AtomicFile写入noBackupFilesDir；不回填、不记录、不进入Room或备份。官方API与ChatGPT订阅分别计费。用户主动点击才调用，不自动重试。进程共用Mutex防止不同入口并发；取消、超时不保证服务端停止处理或计费。生成中禁用外层底栏，通知快捷入口延后，保留当前页取消入口。

结果PNG验证完整IEND尾块、尺寸、字节上限及实际可解码后以UUID文件保存；失败/取消清理未持久化文件。TryOnResult独立保存名称、原服饰ID/名称快照、模型和日期，没有原服饰外键，不影响衣橱归属、真实穿搭或账目。支持放大缩放、重命名和删除。删除复用ImageFileHelper共享引用保护。

## 独立审阅与决策

独立只读审阅未发现Critical项；Important导航离页问题已修。实际NavHost回归先复现底栏仍可用、快捷入口立即跳转，再验证生成时无法离开、可取消、互斥释放且只有一次请求。审阅的按钮旁上传提醒提升为本轮需修项，八件/320dp/两倍字号回归确认提醒和操作同时可见。测试仅关闭NavHost装饰动画和Haze以避免仪器化持续重组，保留实际导航与生成服务。

主要决策及限制：

- 使用当前官方Sunburst型号，沿用medium尺寸直到获得实际API成本和质量数据；若质量不足需调档并重新核价。
- 生成调度放TryOnGenerator，Repository保持薄持久化封装；模型、图片预处理、持久化和界面各有明确边界。
- API Key缺失时交付可配置界面及受控回归，明确未实调；真实权限与服务契约仍需用户填Key后验证。
- 合入已发布2.47.1，不覆盖并行审计修复；签名正式包及覆盖升级证据单列在本次发布验证文件中。
- 人台/三视图本轮仅探索，不增加未经验证的应用模式。原照片没有背面依据，必须标注推测，不用于商品真实结构或尺码判断。
- 后续小项：共享查看器已验证单图pinch，放大后平移与多图翻页组合尚无本轮专项回归。
