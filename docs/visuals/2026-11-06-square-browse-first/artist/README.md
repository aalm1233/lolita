## 构图与事实

详情先用约 310dp 的完整单品图和有图款式切换器表达购买对象，再呈现名称、明确价格阶段、颜色、可后补尺码。下滑直接读材质、版型与独立尺码表。来源、批次长文和完整原图在内容之后，禁止以部件目录代替商品详情。

JSK/KC/内搭材质与尺寸来自修订包经核验明文及对应原图。莉莉子价按本地 SKU：长款 OP 625、短款 OP 610、袖套 175；长短 OP 尺码列分开。尾款页仅显示本批白色 Lady70 的 222 尾款快照，不代表全款，不自动录价。

## 验收与边界

最终 [交互回执](interaction-review.json) 的 **43 项检查通过**：按商品/部件/颜色/尺码识别已有心愿，未选色码可保存；仅 KC 不带裙图或裙码；多件和组合展示真实成员、独立规格，重复不新增；查看心愿返回商品上下文与滚动；第二店价格、原图阅读与放大、金额隐藏、尾款只读，以及七皮肤浅暗和 320dp 两倍字的页面横向边界、缺图及主按钮。HTTP/HTTPS 请求 0，脚本错误 0，原图逐项 SHA 匹配。[渲染回执](render-review.json) 独立记录图板。

原型只在当前页面内暂存心愿，刷新后清空，不写真实衣橱。店铺与类别只筛本地样例；颜色/风格筛选、资料包导入、其他底栏和完整应用导航为视觉示意。示意心愿页用于检查输出对象，不等于已接入现有物品详情。无独立映射时的系列待选心愿、原生重建/持久化/并发、图片失败、TalkBack、真实 IME、备份和全部资料包边界尚未覆盖。

这些是实现前图稿与受控 HTML 检查，不是 Compose、模拟器、真实设备或发布验收。没有上传、付款、网络采集或付费调用。截图渲染和检查脚本强制拦截 HTTP/HTTPS；脚本以 finally 关闭自行启动的浏览器。本轮收尾检查未发现遗留 headless Playwright Chrome 进程，未操作用户浏览器。
