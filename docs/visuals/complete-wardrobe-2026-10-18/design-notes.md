# 初版实现后补充的最终视觉对照方案

日期：2026-10-18。此图稿在初版 UI 实现后补充，用于下一轮视觉修整前的设计对照，不是前置设计图，也不是真实 Android 截图。本轮开始后新增了前置界面图规则，初版没有完成该顺序；此记录保留流程差异。

## 构图与皮肤计划

沿用当前 Android 应用的居中单栏、紧凑渐变顶栏、分区卡片与底部导航。登记先呈现名称、稳定类型、未知品牌和少量专属字段；补充字段由明确展开动作进入。识图以本次实际裁切区域为视觉中心，原文、来源与可修改候选直接对应；应用到草稿与保存物品分别表达。收纳保持房间、柜架、层格的可读完整路径。

本板使用 SkinConfigs.kt / Color.kt 中的真实颜色、卡片表面合成、边框、圆角、间距和字体文件，七套皮肤分别呈现浅暗效果。背景和缩略图引用仓库现有素材，不从网络取图，不生成仿制商品照。HTML/SVG 是可审阅图稿；浏览器字体回退、阴影与 Android 图标 provider 的像素细节以真实 Compose 验收为准。

```
登记：紧凑顶栏 / 基本资料 / 识图入口 / 默认规格 / 更多规格 / 照片 / 位置
识图：明确本次服务 / 实际区域 / 费用确认 / 对照候选 / 原文与口径 / 应用到草稿
收纳：房间概览 / 柜架与层格 / 上下文新增 / 完整路径 / 选择记录 / 明确移动确认
```

对照重点是实际内容密度和动作层次，不额外发明一个衣橱产品页面。默认文字左对齐，图片完整 Fit；说明位于相关字段旁边。七套皮肤的现有构件身份优先于统一的新装饰。按本简报复核后保留既有皮肤色板与字体，删除了最初拟加的额外封面与装饰性编号，避免把比对板变成另一个应用界面。

## 可查看范围

- `final-review.html`：七个关键状态 × 七套皮肤 × 浅暗两种，共 98 幅详细界面；可切换 320/360 宽度、1/1.3/2 倍文字与模拟键盘，内容区可滚动。
- 登记默认与展开：假发默认四项，更多规格按需补充；切类型保留原已填值。其他品类默认项列在说明区。
- 识图准备与对照：本次固定服务/模型、实际区域、显式计费确认、文字/外观/未知分别呈现、尺码行依赖、冲突不默认勾选、应用后仍须最终保存。
- 收纳三流程：房间/柜架详情与新增、完整路径选择、批量移动与确认。删除柜架/层格把记录上移，不删除物品。
- 状态说明：加载、空白、失效引用、旧草稿冲突、请求等待与失败、照片加载失败、隐私关闭和未付费边界见图稿下方状态条。

## 数据与图片边界

本板的名称、数值、数量与尺码表是明确标注的设计样例，不代表真实识别结果或用户库存。局部尺码表使用原生 SVG 绘制；其数值不来自模型。假发模特、房间和收纳缩略图为本地已有素材，只说明展示方式。编辑和详情使用 Fit；房间示意用 Crop；识图仅发送明确确认的裁切副本，来源不自动混入相册；AI 图只提供外观建议。密钥、实付截图不出现在图稿中。

旧分类不按名称赋语义，未知品牌保持未知。应用识图只更改当前草稿，最后保存才写物品字段；价格候选不能形成订单/实付。新的字段、草稿、任务、证据与图片引用继续按数据库/备份校验；删除及清理按真实引用保护。旧草稿与最新已保存资料冲突时保留草稿并阻止覆盖，明确放弃后才重载。

本图稿不代表付费服务成功，不触发 API，也不承担发布验收。真实设备截图与行为日志另放 artifacts/，不能用图稿替代。
